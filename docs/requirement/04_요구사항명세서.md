# 요구사항 명세서 (SRS)

**프로젝트명**: 자산 가계부 — 증권 자산 변화 기록 · 분석 플랫폼
**과목**: 캡스톤설계 | **개발 형태**: 개인 프로젝트 | **작성자**: 오경택
**버전**: v4.1 (방향성 v6 기준)

## 1. 문서 개요

### 1.1 목적
시스템의 기능 · 비기능 요구사항을 정의한다. 모든 FR은 `02_사용자요구사항_유스케이스.md`의 UR에 근거한다.

### 1.2 시스템 범위
CODEF와 시세 API로 증권 · 예적금 자산을 자동 수집해 **일별 자산 기록**을 남기고, 추이와 **월간 결산**을 제공한다(기반). 그 위에서 ① 보유 종목 급등락 시 공시 · 뉴스 · 거시지표를 수집해 관련 근거를 제시하고, ② 투자 목표 대비 진척과 도달 시점 시뮬레이션을 제공하며, ③ 예적금 만기 관리와 정기예금 예상 수령액 비교를 제공한다(핵심). 운영 지표는 관리자 전용으로 수집한다.

### 1.4 용어 정의
| 용어 | 정의 |
|---|---|
| 자산 기록 | 매 영업일 자동 저장되는 사용자 자산 스냅샷. 가계부의 "내역"에 대응. **계좌 연동일부터** 생성 |
| 수집 상태 | 스냅샷의 완전성 — COMPLETE(정상) / PARTIAL(일부 누락) / FAILED(수집 실패) |
| COMPLETE 기록 | 비교 · 감지 · 결산 · 목표 계산에 사용하는 유일한 기준 기록 |
| 시장가격 영향 | 보유 자산의 가격 변동으로 생긴 평가액 변화 |
| 기타 자산 변화 | `총자산 변화 − 시장가격 영향`. 원인을 뜻하지 않는 차이값 |
| 월간 결산 | 한 달 자산 기록 · 이벤트 · 목표 진척을 정리한 리포트 |
| 공유 분석 | 종목 · 날짜 단위로 1회 생성해 여러 사용자가 재사용하는 원인 분석 결과 |
| 사용자 이벤트 | 공유 분석에 사용자별 비중 · 손익을 결합한 레코드 |
| 근거 | 공유 분석의 원인 후보로 수집된 공시 · 뉴스 · 지표 |
| 근거 상태 | 공유 분석의 근거 확인 결과 — 관련 근거 확인 / 시장 · 업종 동반 움직임 / 관련 근거 확인 불가 (v4.1에서 '확신도' 대체) |
| 기본 / 사용자 임계치 | 시스템 초기값 / 사용자가 덮어쓴 개인값 |
| 묶음 알림 | 개별 알림 상한 초과분을 1건으로 합친 알림 |
| 운영 지표 | 관리자가 Grafana로 확인하는 시스템 측정값. 사용자 화면에 노출하지 않음 |
| `[확인 필요]` / `[구현 시 확정]` | 방향만 확정하고 결정 시점을 미룬 항목. 01 방향정의 §14에서 일괄 관리 |

### 6.1 제약사항
| 구분 | 내용 |
|---|---|
| 법 · 제도 | 마이데이터 자격 없음 → CODEF 경유 수집 |

| 표현 | 금융상품은 "추천"이 아닌 "비교" |
| 표현 | AI 사용량 · 비용을 사용자에게 노출하지 않음 |
| 기능 | 주식 매매 · 자금 이동 미구현 |
| 기능 | 지출 내역 · 카드 연동 · 지출 분류 제외 |

- 기존 프로젝트의 CODEF 연동 · 암호화 · 인증 모듈을 이식한다
