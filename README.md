# Assetory

> 지출을 기록하는 가계부처럼, **자산의 변화를 기록**하고 분석 · 비교해 자산을 늘리도록 돕는 **자산 가계부**

Asset + History/Story — 자산이 얼마나 변했는지 기록하고, 그 시점에 어떤 일이 있었는지 근거와 함께 보여줍니다.

캡스톤설계 개인 프로젝트 · 15주 (~ 2026.12)

## 주요 기능

| 구분 | 기능 |
|---|---|
| 기반 | 자산 변화 자동 기록 (CODEF · 시세 API), 전일 · 전월 · 전년 추이, 월간 자산 결산 |
| 핵심 ① | 보유 종목 급등락 감지 → 같은 시점의 공시 · 뉴스 · 거시지표 근거 수집 및 요약 |
| 핵심 ② | 투자 목표 진척률, 도달 예상 시점, 시나리오 시뮬레이션 |
| 핵심 ③ | 예적금 만기 관리, 정기예금 예상 수령액 비교 (목표 시점 기준) |
| 전달 | 웹 푸시 · 이메일 알림, 원인 · 결산 · 목표 페이지 |
